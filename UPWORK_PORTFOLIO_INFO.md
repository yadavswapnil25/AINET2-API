## Project Description

Developed a comprehensive web platform and content management system for AINET (Association of Indian Teachers of English), a professional organization for English language teachers in India. The project consists of three integrated applications: a public-facing website, a RESTful API backend, and an admin management panel.

**Key Achievements:**
- Built a scalable Laravel 12 REST API with OAuth2 authentication using Laravel Passport
- Developed a modern React-based public website with responsive design using Tailwind CSS
- Created a comprehensive admin dashboard for content management with real-time data synchronization
- Integrated Razorpay payment gateway for membership subscriptions and event registrations
- Implemented live webinar streaming functionality supporting YouTube, Facebook, Zoom, and custom embeds
- Designed and implemented database schema with migrations for 15+ content modules
- Built form submission system with PDF receipt generation and email notifications
- Implemented bulk operations, data export (Excel), and advanced filtering capabilities

**Technical Implementation:**
- **Backend**: Laravel 12 (PHP 8.2) with MySQL database, implementing RESTful API architecture
- **Frontend**: React 18/19 with React Router, Tailwind CSS, and Vite for build optimization
- **Admin Panel**: React 18 with React Hook Form, React Query for state management, and Zustand for global state
- **Authentication**: OAuth2 with Laravel Passport, JWT tokens, and refresh token mechanism
- **Payment Processing**: Razorpay integration with order creation, payment verification, and refund handling
- **File Management**: Image uploads, PDF generation using DomPDF, Excel export using PhpSpreadsheet
- **Email System**: Custom email templates with Laravel Mail for notifications and confirmations

**Impact:**
The platform successfully manages membership registrations, event/webinar hosting with live streaming, content publication (blogs, news, galleries), and provides a seamless user experience for both public visitors and administrators. The system handles complex workflows including membership discounts, payment processing, form submissions (DRF/PPF), and newsletter subscriptions.

## Project Architecture

**Three-Tier Architecture:**
1. **Backend API** (Laravel) - Handles all business logic, database operations, authentication, and third-party integrations
2. **Public Website** (React) - User-facing website with dynamic content, event listings, membership plans, and live streaming
3. **Admin Panel** (React) - Content management system for administrators to manage all aspects of the platform

**Database Schema:**
